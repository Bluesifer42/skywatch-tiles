# skywatch-tiles

Tile pyramids for the Skywatch astronomy game's pan-and-zoom catalogue. Served via GitHub Pages.

Layout: `tiles/<target>/manifest.json` and `tiles/<target>/<z>/<x>_<y>.jpg` (256 px tiles, level `maxZoom` is full resolution, each lower level halves it). `index.json` lists targets. Generated by `tools/make_tiles.py` in the game repo from the originals in `sources/`.
